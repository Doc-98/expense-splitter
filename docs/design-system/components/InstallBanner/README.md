# InstallBanner

The one-time floating shelf offering to install the PWA — the only element with `shadow-floating` (much stronger in dark, so it still lifts off the near-black page). Fixed `space-md` from the bottom and sides, max 480px, `surface` with a `border` and `radius` corners.

- Left: the 34px app mark (`accent`, Fraunces "S", 8px radius (`radius-sm`)); middle: a 14px bold title and a 12px muted line; right: the action and a × dismiss in `ink-soft`.
- Show once; dismissing remembers the choice.
