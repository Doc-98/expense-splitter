# Modal

A centered dialog for tasks with content — multiple payers, typed "delete all" confirms: `surface` panel, `radius` corners, `space-lg` padding, max 420px wide and 85vh tall (scrolls inside), over the `scrim`.

- `sheet-title` h2, then content, then `.modal-actions` right-aligned with `space-md` gaps: `btn-secondary` Cancel before the primary action.
- Consumer provides the title, body, and the actions; Escape and backdrop tap close it.
